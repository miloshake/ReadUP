# ReadUP

ReadUP is a website idea for helping people practice reading English out loud. It is still a work in progress.

## What it does

- Lets you choose an easy, medium, or hard paragraph
- Listens while you read and shows which words you got right
- Lets you type your reading if voice recognition does not work

## How to try it

Open `Read Aloud – Reading Practice (prototype).html` in a browser. Chrome or Edge works best for the voice feature.
